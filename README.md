# Привет! Я — Начинающий аналитик данных (Junior Data Analyst) 👋

Ищу позицию **Junior Data Analyst / Product Analyst**. Умею работать с «сырыми» данными, писать читаемый SQL-код с оконными функциями, автоматизировать очистку данных на Python и переводить метрики на язык бизнес-результата в тенге (KZT).

### 🛠 Технический стек
* **SQL:** PostgreSQL, ClickHouse (сложные запросы с `JOIN`, `CTE / WITH`, оконные функции `ROW_NUMBER`, `LAG`, `SUM() OVER`).
* **Python:** `pandas`, `numpy` (очистка данных, работа с выбросами), `scipy`, `statsmodels` (проверка гипотез, A/B-тесты), базовый `scikit-learn`.
* **BI и визуализация:** Tableau, Power BI, Streamlit, Matplotlib, Seaborn.
* **Бизнес-метрики:** Юнит-экономика (CM1/CM2, LTV, CAC), когортный анализ (Retention, Churn), воронки конверсии.

### 🚀 Учебно-практические проекты в портфолио (Pet-Projects, Рынок РК ₸)
*Все проекты выполнены на смоделированных данных, приближенных к реальным кейсам e-commerce, SaaS и финтеха Казахстана.*

1. **[Аудит юнит-экономики и очистка транзакционных данных e-commerce](https://github.com/abusagievo-collab/ecommerce-unit-economics-audit)**
   * **Задача:** Очистка выгрузки заказов из дублей и аномалий доставки, поиск убыточных товаров при использовании промокодов.
   * **Стек:** `PostgreSQL`, `Python`, `pandas`, `re`.
   * **Моделируемый бизнес-эффект:** Выявление 12% убыточных SKU и корректировка правил промокодов позволяет сократить потери на возвратах на **7,2 млн ₸/мес.**

2. **[Продуктовая аналитика и когортный анализ удержания в B2B SaaS](https://github.com/abusagievo-collab/b2b-saas-retention-analytics)**
   * **Задача:** Анализ воронки онбординга, поиск ключевого действия активации («Aha-moment») и расчет выборки для A/B-теста.
   * **Стек:** `SQL`, `Python`, `scipy.stats`, `statsmodels`.
   * **Моделируемый бизнес-эффект:** Выявлена связь между приглашением коллеги в первые 48 часов и ростом конверсии в оплату с 4,2% до 14,3% (в **3,4 раза**).

3. **[Скоринг оттока клиентов банка (Churn) и калькулятор ROI в тенге](https://github.com/abusagievo-collab/fintech-churn-prediction-app)**
   * 🔗 **[Открыть интерактивное демо-приложение (Streamlit Cloud)](https://fintech-churn-prediction-app-ug7h8h872lyzngirg7n3ph.streamlit.app)**
   * **Задача:** Оценка вероятности ухода держателей карт и расчет оптимального порога для отправки кэшбэк-бонуса.
   * **Стек:** `SQL`, `Python`, `scikit-learn`, `Streamlit`.
   * **Моделируемый бизнес-эффект:** Точечная отправка бонусов топ-15% рисковых клиентов вместо массовой рассылки снижает затраты на бонусный фонд в **2,6 раза**.
